# Layer 0 Structural Specification

## Page anatomy

* Breadcrumb navigation
* Hero section
* Overview section
* Subtype-specific content
* Venue section
* FAQ section
* Related events section
* Footer

## Interlinking pattern

Home → City → Subtype → Event

Each event page must:

* link back to its city page,
* link to at least 3 related events,
* include visible breadcrumbs.

## Visible SEO signals

* H1 heading
* Meta title
* Meta description
* Canonical URL
* Breadcrumbs
* FAQ section

## URL format

/{city}/{subtype}/{keyword}

Examples:

* /nairobi/conference/ai-summit
* /mombasa/wedding/beach-wedding-expo
